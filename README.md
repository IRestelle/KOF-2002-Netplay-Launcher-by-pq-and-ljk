# -2002-
KOF 2002 Netplay Launcher 是一个面向 Windows 的拳皇 2002 双人联机启动器项目，用于简化 RetroArch + FinalBurn Neo 的联机配置流程。项目提供一键创建主机、一键加入对战、手柄/摇杆按键映射、低延迟配置切换、Radmin VPN / Tailscale 虚拟局域网联机辅助脚本等功能，让两名玩家可以更方便地通过私有网络进行稳定对战。 本项目只包含启动器源码、配置模板、联机脚本和使用文档，不包含任何 ROM、BIOS、模拟器运行时文件或受版权保护的游戏内容。玩家需要自行准备合法获得的游戏文件，并按说明放入本地运行目录。
